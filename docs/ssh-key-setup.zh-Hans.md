# SSH 密码登录与一键配置免密

macOS/Linux 桌面客户端和 Windows 客户端均提供原生 SSH 节点。新建节点默认使用密码认证；填写服务器地址、端口、用户名、密码，确认服务器公钥指纹后点击「确定」即可保存。密码登录可以独立使用，不必先配置免密。

## 选择本地私钥或重新生成

在 SSH 节点编辑窗口勾选「使用私钥认证」，再点击「一键配置免密…」，确认服务器指纹后进入配置窗口。密码认证模式下隐藏此按钮。

- 发现本地私钥时，选择「复用已有私钥」或「重新生成私钥（保留旧密钥）」。列表显示文件路径、算法、公钥指纹及加密状态；默认选中上次保存的共享密钥，仍需点击验证。
- 候选来自当前表单、已保存 SSH 节点引用、应用的 `sshKeys` 目录和 `~/.ssh` 中的普通文件，不递归扫描。其他位置通过「浏览」手动选择。
- 加密私钥需要正确口令才能使用。OpenSSH 格式可在解密前显示公开的算法和指纹，其他加密格式可能要解密后才能显示完整信息。服务器密码与私钥口令分别输入。
- 复用直接引用原文件，不复制或修改它，也不自动调整权限。「本地可用」表示密钥可读取解析，服务器是否接受仍需单独验证。
- 重新生成使用固定版本 SshNet.Keygen 2026.0.0 创建 Ed25519 OpenSSH 私钥，可选设置私钥口令，默认不设置。每次明确生成都创建新文件，不覆盖旧文件，不改变旧节点引用。

## 安装和保存

复用时先尝试仅使用所选私钥登录；已获授权的密钥不需要服务器密码。只有认证被拒绝才提示输入服务器密码安装公钥，网络错误或主机指纹变化不会自动降级到密码认证。

生成新密钥时，先用服务器用户名和密码登录成功，再生成并保存私钥。安装仅向当前登录账号的标准 `~/.ssh/authorized_keys` 追加公钥，保留已有内容、注释及限制选项，相同公钥不重复追加。随后关闭密码连接，重新建立仅使用私钥的连接验证。

验证成功后，编辑表单自动切换到私钥认证并回填路径。**点击「确定」才保存节点，同时记住所选的共享默认密钥。** 配置免密不会切换当前代理。取消编辑不会更新默认项，已生成的私钥仍保留。多个节点可以引用同一把密钥，每次配置仍可重新选择。

密钥登录成功不代表服务器允许代理转发，请使用编辑窗口的「测试连接」，或保存后的节点真连接测试。SSH 节点使用 sing-box，当前验收使用 1.14.3；旧版 1.13.11 不兼容本仓库生成的部分 DNS 字段。SSH 节点当前仅提供 TCP 代理。

## 保存前测试连接

添加或编辑 SSH 节点时，底部「测试连接」支持密码和私钥两种认证方式。先确认服务器身份，再分别验证「SSH 登录」和「代理访问」，展示各阶段结果、耗时，以及设置中的真连接测试网址。

- 测试使用当前表单，不保存或激活节点、不更新共享默认密钥，也不写入节点测速记录。
- 代理访问启动独立的临时 sing-box，使用受认证保护的本机监听端口，所有请求固定经过此 SSH 节点；当前系统代理及路由配置不变。
- HTTP 成功响应显示「通过」；其他状态码显示「目标已响应」及状态码，重定向不会自动跟随。HTTPS 保持证书校验。登录成功但转发失败时，请检查服务端 TCP 转发权限及目标可达性。
- 测试期间锁定表单，「停止测试」保留窗口及输入；关闭窗口也会取消。完成、失败或取消后清理临时进程及受限权限的凭据文件。
- 修改连接参数或凭据后清除旧结果，修改别名不影响结果。测试不是保存的必要条件，仍由用户点击「确定」保存。

SSH 连接超时为 12 秒、核心启动 5 秒、HTTP 请求 5 秒，确认身份后整体最长 30 秒。认证失败、主机指纹变化、核心缺失或不兼容、TLS 失败及超时分别提示；不会因失败自动切换认证方式或安装公钥。

## 失败恢复与手动安装

首版自动安装支持具备命令执行能力、标准家目录和 GNU 工具的 Linux/OpenSSH 账号。权限不安全、归属不符、符号链接、并发修改、非标准授权位置或受限命令环境会停止安装；程序不修改 SSH 服务配置、不关闭密码认证、不重启服务。

取消、断线或写入失败可能发生在服务器已添加公钥之后，**取消不撤销已经完成的安装**。程序保留本地私钥及不含秘密的阶段记录。重试优先使用同一把密钥验证登录，需要安装时重新核查远端并去重，不应为一次失败反复生成替代密钥。

重启后可从候选列表再次选择保留的密钥。其他服务器环境可选中并复制窗口中的公钥，按服务器要求追加到该账号的授权位置，保留原有限制，再点击验证。不要把私钥上传到服务器。服务器禁止公钥认证时，仅写入公钥不能算成功，程序不会自动保存或切换认证模式。

## 存储与备份

托管私钥保存在应用数据目录的独立 `sshKeys` 下，与 `guiConfigs` 并列。Unix 新目录权限为 `0700`、新私钥为 `0600`；Windows 使用限制当前用户的 ACL。外部私钥权限不符合要求时会提示，用户自行处理。

现有配置备份和 WebDAV 同步只覆盖 `guiConfigs`，**不包含托管私钥**。跨设备迁移需要单独妥善保存私钥，或在新设备重新生成并安装。删除节点不会删除密钥。本次不提供远端撤销、密钥轮换或跨设备密钥同步。

安装用服务器密码在每次尝试后清除，不写入节点或操作记录。保存加密私钥节点时，私钥口令沿用现有节点凭据存储方式；共享默认项只存储路径和公钥身份，不另存全局口令。
